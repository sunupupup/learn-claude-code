# OpenFilm

OpenFilm 用网页表达影片，并提供本地 Studio 编辑器与命令行工具，支持已有编程 Agent 制作、预览和修改视频。
本次将其作为编程 Agent 的视频制作工具与支撑程序学习，先观察各部分如何衔接。
