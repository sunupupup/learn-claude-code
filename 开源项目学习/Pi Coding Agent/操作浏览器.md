# pi-agent-browser-native

这个插件提供的能力 

它把底层 agent-browser 工具接入 Pi，让模型能打开网页、点击、填表、截图等。

Pi → Pi 扩展插件 → agent-browser → 浏览器

# agent_browser 工具

## 发起调用
```js
agent_browser({
  args: [
    "--session", "login-test-a",
    "open", "http://localhost:3001"
  ]
})

// 关闭
agent_browser({
  args: ["--session", "login-test-a", "close"]
})
```

session A → Chrome 实例 A → 用户数据目录 A
session B → Chrome 实例 B → 用户数据目录 B

通过指定不同的用户数据目录，来实现数据的隔离

简化成你熟悉的命令，就是：

```powershell
chrome.exe --user-data-dir=D:\temp\browser-a
chrome.exe --user-data-dir=D:\temp\browser-b
```

底层 Chrome 的能力：通过 --user-data-dir 指定独立的浏览器用户数据目录。

## 观察页面、交互页面

```js
// 获取页面元素
agent_browser({
  args: ["--session", "login-test-a", "snapshot", "-i"]
})

```

```js
agent_browser({
  args: ["--session", "login-test-a", "fill", "@e1", "测试账号"]
})

agent_browser({
  args: ["--session", "login-test-a", "fill", "@e2", "测试密码"]
})

agent_browser({
  args: ["--session", "login-test-a", "click", "@e3"]
})
```

## 保存快照

```js
agent_browser({
  args: [
    "--session", "login-test-a",
    "screenshot", "D:/temp/pi-browser-e2e/login-result.png"
  ]
})
```


## 关闭 


```js
agent_browser({
  args: ["--session", "login-test-a", "close"]
})
```


# 关于快照

快照知识获取页面数据的一种方式
多种方式一般都有各自的适用场景

| 方式 | 适合获取什么 |
|---|---|
| `snapshot` | 页面语义结构、控件及引用 | 
| `get text` | 指定元素的文本 |
| `get html` | 指定元素的 HTML |
| `get value`、`get attr` | 输入值、属性 |
| `screenshot` | 外观、布局、图表等视觉信息 |
| `eval` | 执行 JavaScript，按需要提取数据 |



找登录按钮 → snapshot
读某段文字 → get text
提取一批表格或链接 → eval
检查页面布局 → screenshot

## snapshot

快照的形式

agent-browser snapshot
直接输出完整的html树


加上 -i 参数， 保留的是各种交互元素，AI友好

@e1 [textbox] "邮箱"
@e2 [textbox] "密码"
@e3 [button] "登录"
@e4 [link] "忘记密码"

后续可以直接 agent-browser click @e2


截图导出到图片
agent-browser screenshot --annotate ./page.png
