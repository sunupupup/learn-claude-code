# screenshot-to-code：截图到代码与视觉反馈

## 学习问题与范围

- 当前问题：上传一张截图后，前后端如何把它交给模型生成代码，并显示在预览里？
- 相关子问题：截图与指令如何组织为模型输入；工具执行怎样改变代码状态；渲染截图怎样交回模型进行视觉检查；模型何时继续修改或结束。先追一次生成，不展开多候选比较、评测与完整工程构建。
- 进度：已初始化。
