# OpenDesign

人与 AI Agent 协作的设计工作台，可用于原型、幻灯片和其他设计产物。
本次先研究工作台本体如何组织设计任务并接入已有编程 Agent，逐步追踪产物预览。

- 官方仓库：https://github.com/nexu-io/open-design
- 本次研究范围：`apps/web` 与 `apps/daemon` 的本地 CLI 设计任务路径。
