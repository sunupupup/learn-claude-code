# 11. Skill推荐与适配评分

## 使用场景

用户要分析 Excel 并画图；系统有表格、可视化和 PPT 等多个 Skill（任务技能说明）。

## 在 Harness 中的作用

- 接入位置：在推荐或加载 Skill 前判断本轮需要哪些能力，以及候选与需求的匹配程度。
- 数据流：用户需求 + 技能描述 → Jev 排序或逐项评分 → 程序复核候选并展示推荐，也允许不推荐。
- 职责边界：为技能选择提供可比较的信号；推荐不代表已经安装、加载、获授权或成功执行。

## 最小实操目标

用 5 个 Skill 和 3 条需求，对比明确匹配、多技能协作、没有合适技能。

`Choice` 用于候选间选择与相对排序；`Score` 按明确等级独立评分，允许多个技能同时适合。分数不等于执行成功率。
