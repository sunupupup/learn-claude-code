# 4. 相似问题是否可以复用缓存

## 使用场景

两个问题几乎一样，但查询的是不同租户，或不同月份的数据。

## 在 Harness 中的作用

- 接入位置：在缓存命中后、返回旧答案前，判断问题语义和使用范围是否仍一致。
- 数据流：新请求 + 缓存问题及范围 → Jev 辅助判断等价性 → 程序复用或重新计算。
- 职责边界：减少语义相似但业务范围不同的错误复用；租户、权限、有效期必须先做确定性校验。

## 最小实操目标

只改变租户、日期或查询条件，观察哪些变化必须使缓存失效。
