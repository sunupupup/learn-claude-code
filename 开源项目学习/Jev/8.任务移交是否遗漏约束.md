# 8. 任务移交是否遗漏约束

## 使用场景

原始要求含“不要部署”，交给下一个 Agent 的摘要却遗漏了这条限制。

## 在 Harness 中的作用

- 接入位置：在任务移交或上下文压缩后，检查关键约束、未完成事项和不确定性是否保留。
- 数据流：原始要求 + 移交摘要 → Jev 判断遗漏或失真 → 程序补齐或阻止移交。
- 职责边界：减少跨 Agent 或跨轮次的信息丢失；重要约束应单独保存在结构化状态中。

## 最小实操目标

对比完整摘要、丢失否定词、把待验证写成已完成三种摘要。
