## 运行 Demo

需要 Node.js 22+，无需安装依赖。从仓库根目录执行：

```powershell
node 开源项目学习/Jev/basic.js --dry-run
node 开源项目学习/Jev/basic.js
node 开源项目学习/Jev/basic.js "不用着急，我只是想了解退款流程。"
```

真实请求使用环境变量 `ZHIZENGZENG_API_KEY`；也可复制本目录 `.env.example` 为 `.env` 后填写。`.env` 被 Git 忽略，不要把 Key 写进脚本。真实调用可能消耗渠道额度。
默认只发一个问题、一次请求；不自动重试。脚本展示原始响应、HTTP 状态和端到端耗时，并校验 `answers.is_urgent.noul` 是否在 0～1 之间。耗时包含网络和中转，不等于模型自身推理耗时。
