# 5. HTTP200是否代表任务完成

## 使用场景

导出接口返回 HTTP 200，但任务只是排队，尚未产生可下载文件。

## 在 Harness 中的作用

- 接入位置：在工具返回后检查业务完成条件，再决定等待、查询状态或结束任务。
- 数据流：用户目标 + 工具结果 + 完成条件 → Jev 辅助识别未满足项 → 程序推进后续步骤。
- 职责边界：避免把协议成功当作任务完成；文件存在、任务状态等可直接查证的事实仍由工具核验。

## 最小实操目标

对比“已排队”和“已生成且可下载”的结果，看是否过早宣告完成。
