## 我的笔记


### 记录
针对于某些 action + object 的组合

宿主触发生命周期事件／Hook
    ↓
Context Mode 接收工具参数、结果或用户消息
    ↓
按程序规则提取结构化事件
    ↓
写入 SQLite
    ↓
对话压缩或恢复后
    ↓
将选中的工作状态补进上下文
其余历史提供检索入口

### 恢复

这里的“恢复”是：让模型重新知道之前发生了什么，不是重新执行那些动作。

模型需要历史线索时，用 ctx_search 查询相关事件，再继续工作。

```
准备继续修支付问题
    ↓
搜索之前的支付错误、修改记录和用户要求
    ↓
取回相关事件
    ↓
结合当前文件状态继续处理
```

它本身有几种方式
1. 一个是提醒模型，可以在做关键操作的时候，比如改一个我呢见，提前用 ctx_excute 查一下相关的内容
2. 在 loop 开始前，作为 user message 插入一些 比如 近50条关键的事件
