## 他的沙箱、执行隔离 机制

Context Mode 收到一段 Python 代码
    ↓
在本机创建临时目录
    ↓
把代码保存成临时脚本
    ↓
启动本机的 Python 程序执行脚本
    ↓
收集打印结果
    ↓
执行结束后清理临时脚本

| 部分 | 实际效果 |
|---|---|
| **程序内存和变量** | 代码在独立进程里执行，没有直接混进 Context Mode 自己的变量空间 |
| **临时脚本** | 每次执行使用独立临时目录，结束后清理 |
| **输出进入模型的路径** | 原始数据在执行环境中处理，程序打印的内容才交回 Context Mode，再决定怎样返回模型 |
| **部分运行控制** | 清理部分环境变量、限制收集的输出量；显式设置超时时，可以结束执行 |
