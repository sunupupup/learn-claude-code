## 我的笔记


### 提示去重

有意思

```text
调用前 Hook 触发
    ↓
判断本次需要哪类提醒：Read／Grep／Bash……
    ↓
当前会话中，这类提醒是否已经发过？
    ├─ 没发过 → 发出提醒，并保存标记
    └─ 发过了 → 不再追加同一类提醒
```

会强行提醒：

“分析文件时，可以使用 ctx_execute_file，只返回处理结果。”

但是总不能一直提示吧 
所以他会想办法去重
倒是有好几种办法去重
1. 进程用 Set 保存下 session id，已经标记过了
2. 用临时文件 <临时目录>/context-mode-guidance-s-<会话ID>/read
3. 甚至存在sqlite都行

### 不可用降级

Hook 准备拦截原工具、要求改用 ctx_* 之前，先检查 Context Mode 是否可用。

Agent 准备用 Bash 执行 curl
    ↓
Hook 阻止它，要求改用 ctx_fetch_and_index

Hook 准备返回“改用 ctx_*”的决定
    ↓
当前调用环境允许使用这些 MCP 工具吗？
    ↓ 是
有没有已就绪的 Context Mode 服务？
    ├─ 有 → 返回原来的拦截／改写决定
    └─ 没有 → 放弃这次路由干预，让原调用继续


核心点也就是 

```js
function mcpRedirect(result, mcpToolsAvailable = true) {
  if (!mcpToolsAvailable) return null;
  if (!isMCPReady()) return null;
  return result;
}
```
