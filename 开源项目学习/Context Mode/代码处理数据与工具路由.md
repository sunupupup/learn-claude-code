## 我的笔记

这个其实是think in code的体现

Think in Code 主要靠提示词：要求模型生成数据处理代码，让程序计算，只把结果打印出来。

“分析、计数、过滤、比较、搜索、解析、转换数据时，通过 ctx_execute 编写并执行代码，只打印答案。不要把原始数据全部读进模型上下文再处理。”
