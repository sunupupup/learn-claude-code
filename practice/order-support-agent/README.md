# 订单客服 Agent

通过一个订单售后场景，逐步学习如何让模型调用业务工具，以及如何由程序控制授权、执行和恢复。

目标场景：

> 昨天买的耳机还没发货，我周五就要出差了。能赶上就催一下，赶不上就退款。

完整学习背景与分阶段计划见 [Notion：案例——订单 Agent 处理用户退款](https://app.notion.com/p/Agent-3efd850183c580afa4b5f2371026b99c)。本目录维护实际实现与验证进度，不复制整份讨论笔记。

## 第一阶段：最小模型与工具循环

目标是跑通一次真实模型驱动的模拟订单查询：

```text
用户在命令行询问订单
→ 模型提出查询订单的工具调用
→ 程序执行模拟查询工具
→ 将工具结果交回模型
→ 模型回答用户
```

本阶段先假设只有一个匹配订单，使用内存对话历史，并设置模型调用次数上限。业务接口使用模拟数据，暂不实现退款、网页或重启恢复。

验收时需要能运行一次完整查询，并看清工具名称、参数、返回结果，以及下一次模型请求实际收到的工具结果。
