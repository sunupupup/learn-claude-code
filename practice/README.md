# Agent 实战项目

`practice/` 用于存放自己动手实现的 Agent 实战项目，把课程中学到的工具调用、上下文管理、权限控制、状态恢复与评估等知识组合起来，形成能够运行和验证的应用。

## 目录分工

- 章节目录（`sXX/`）：学习课程中的机制，保存对应教学代码与章节笔记。
- [`learning-notes/`](../learning-notes/)：保存专题学习总结、源码阅读与实验记录。
- `practice/`：每个子目录是一个自己的实战项目，包含代码、运行说明和阶段验收记录。
- [`specs/`](../specs/README.md)：按仓库规范管理需要追踪的需求、变更与决定。

第三方项目源码仍放在仓库外；已有的 `projects/` 项目保持原位置，新实战项目从这里开始。

## 实践方式

1. 每个项目先明确要解决的问题、学习目标和当前阶段的验收标准。
2. 在同一个项目上逐阶段增加能力，每个功能阶段结束时，都应有能运行、能演示、能验证的版本。
3. 每阶段先说明范围，再实现与运行验证，随后讲解关键代码；理解并确认后再进入下一阶段。
4. 关键逻辑补充中文注释，说明数据流、状态变化和设计原因。
5. 区分已实现、已验证和暂不支持的能力；模拟接口跑通不代表真实生产接入已验证。
6. 各项目在自己的 README 中维护运行方法和当前进度，按需增加学习笔记与验收记录，不提前堆积框架和空目录。
