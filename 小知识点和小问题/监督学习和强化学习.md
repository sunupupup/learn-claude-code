# 简介
监督学习是“拿着标准答案学”，强化学习是“根据行动后的奖励学”。

| | 监督学习（Supervised Learning） | 强化学习（Reinforcement Learning） |
|---|---|---|
| 提供什么 | 输入和对应的目标答案／标签 | 环境，以及行动后的奖励信号 |
| 怎么学 | 预测结果，与标签比较，再调整参数 | 尝试行动，根据奖励调整策略 |
| 例子 | 给图片标注“猫／狗”，训练分类器 | 让程序玩游戏，根据得分学习怎样行动 |



监督学习：像老师给例题和答案。模型先预测，再根据与答案的差距调整。
强化学习：像练习打游戏。不直接告诉你每一步怎么走，而是根据行动后的得分，逐渐学会更好的策略。


强化学习的挑战：探索哪些行动能得到好结果。
监督学习的挑战：从已有样本学出能适用于新样本的规律。

# 他们是根据已有模型训练，还是从头训练 ？？

两种都可以。

监督学习／强化学习，和“从头训练／基于已有模型训练”，是两个不同维度。
- 监督／强化：决定用什么反馈来学习。
- 从头／基于已有模型：决定参数从哪里开始。

# 训练数据量

1 万条高质量数据已经是比较充足的规模。

甚至可以这样判断：
- 1,000～3,000 条：验证方法是否有效。
- 3,000～5,000 条：通常能看到明显的行为变化。
- 8,000～10,000 条：足以覆盖更多边界情况，形成比较稳定的行为。
- 30,000 条以上：除非工具种类、业务领域非常多，否则收益可能开始递减。
