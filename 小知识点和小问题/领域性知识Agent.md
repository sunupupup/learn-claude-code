# 核心观点

对于特定领域的知识，微调、强化学习效果其实不是很好，基本上还是 RAG 和 知识图谱

私域的内容，最好的方式，还是预训练，持续预训练

微调，主要是训练某个能力，强化学习，增强某种能力

但是预训练代价太大，真进行这种操作的公司很少，除非真的像做领域特定的模型

如果RAG的召回率有问题，那就训练向量模型
最好是围绕着  RAG 的生态和技术区优化，分块、提示词 等等 

如果，还是没用，效果不好
那就只能微调了

但是模型，确实可能会对原模型产生一定影响

# 依据

## 领域知识优先考虑 RAG，微调灌知识效果不太好

《Fine-Tuning or Retrieval?》比较了通过文本继续训练与 RAG 引入知识的效果：在论文所测的知识密集任务中，RAG 持续优于前者，模型通过训练吸收新事实比较困难

https://arxiv.org/abs/2312.05934


## 私域内容适合持续预训练

持续预训练，就是在已有模型上继续用领域文本做语言模型训练，让参数进一步适应该领域的表达和知识分布。

《Don’t Stop Pretraining》在多个领域和任务上验证了领域适应预训练的收益。https://aclanthology.org/2020.acl-main.740/

因此，如果目标是让模型本身更熟悉某个领域，这条路线有明确依据。
