agent-browser v0.38.1，默认 Chrome 路径是自己直接调用 CDP

Playwright 操作 Chrome／Chromium 时，底层也是 CDP

| 浏览器 | 底层控制方式 |
|---|---|
| Chrome／Chromium | CDP |
| Firefox | 对应的 Firefox 自动化协议 |
| WebKit | 对应的 WebKit 调试协议 |

CDP，全称 Chrome DevTools Protocol，就是 Chrome 提供的一套“让外部程序控制、检查浏览器”的通信协议。

你可以把它理解成：Chrome 给程序用的控制接口。

意思是：Chrome，请在页面里执行 document.title，把网页标题返回给我

```json
{
  "id": 1,
  "method": "Runtime.evaluate",
  "params": {
    "expression": "document.title"
  }
}
```

把 cdp 理解为，浏览器自己的一套特殊的通信协议是吧
其实就是有特殊约定value格式的json

通常有两种传输方式：WebSocket 或进程管道。CDP 规定消息内容，传输方式负责把消息送过去。
