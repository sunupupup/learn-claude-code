很多个人助手的Agent，有很多种的memory

| 文件 | 保存什么 | 例子 |
|---|---|---|
| `USER.md` | 用户背景、稳定偏好 | 用户做后端开发，偏好中文解释 |
| `MEMORY.md` | 长期事实、重要决定、经验 | 家庭网络的部署约定 |
| `SOUL.md` / `IDENTITY.md` | 助手的角色、表达方式、行为原则 | 回答简洁，行动前确认关键歧义 |
| `TOOLS.md` | 当前环境与工具的使用约定 | 哪个设备名对应客厅音箱 |
| `daily/日期.md` | 当天经历与工作记录 | 今天处理了什么、留下什么问题 |
| `SCRATCHPAD.md` | 尚未完成的事情 | 下周继续检查备份 |


但是像 USER.md  MEMORY.md  SOUL.md，其实等级层面都是顶级的
“不分贵贱，只按职责划分”这个理解是对的。

完全可以把它们看成“按主题拆开的常驻记忆”。

甚至可以理解为 记忆的懒加载
