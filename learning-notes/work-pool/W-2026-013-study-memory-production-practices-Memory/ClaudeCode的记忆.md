# Claude Code 的记忆

首先是4层

| 层 | 存什么 | Harness 怎么用 |
|---|---|---|
| 会话记录 | 用户原话「项目甲**这次**排查先用 npm」 | 后台整理时回查，确认适用范围 |
| 记忆笔记 | 「项目甲那次排查临时用了 npm」 | Agent 问到那次经历时按需读 |
| 主题组织 | 「项目甲依赖排查」页面，汇集几次相关经历并附上来源 | 从索引找到主题页，需要时再追证据 |
| 预注入上下文 | 「默认用 pnpm」，或一条指向项目约定的索引 | 创建新会话时，由 Harness 选定并放进上下文 |


| 从底到顶 | 这一层放什么 | 对应到我们的例子 |
|---|---|---|
| **会话记录（Transcripts）** | 可搜索的原始记录，用来查证 | 用户原话「项目甲**这次**排查先用 npm」 |
| **记忆笔记（Memory notes）** | 从某次经历里记下的事实、决定和经验 | 日期笔记写「项目甲那次排查临时用了 npm」 |
| **记忆组织（Memory representations）** | 按主题整理的页面或 Wiki，可以链接回笔记和证据 | 「项目甲依赖排查」页面汇集几次排查过程，并指回各次记录 |
| **预注入上下文（Injected context）** | Harness 在新会话启动时自动加载的少量内容 | 「安装依赖默认用 pnpm」，或者一行指向包管理器约定的索引 |
