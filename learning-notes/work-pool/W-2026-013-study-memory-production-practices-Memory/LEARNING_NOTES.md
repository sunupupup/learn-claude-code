## 术语速查

| 术语 | 所属层与含义 | 边界 |
| --- | --- | --- |
| Memory，跨会话记忆 | 应用层保留供未来调用使用的信息 | 不等于模型权重或全部聊天日志 |
| Harness，Agent 执行框架 | 应用侧安排模型、工具、上下文和生命周期 | 负责何时调用记忆能力，具体职责依实现核验 |
| Context，上下文 | 一次模型调用实际可见的输入 | 数据已存储不代表已经进入本次请求 |
| Recall，召回 | 从存储找出候选记忆 | 检索结果仍需被程序或工具链交给模型 |
| Consolidation，整理 | 合并或重组已有记忆 | 与每次提取和显式更新分别考察 |
| Embedding，向量表示 | 把文本转为可比较的数值表示 | 是检索手段，不是完整 Memory 系统 |
