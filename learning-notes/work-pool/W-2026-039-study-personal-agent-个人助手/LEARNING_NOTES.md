## 学习位置与模式

这条线接在总路线的真实产品对照上，位置在编程 Agent、Memory、Context 缓存之后，用来回答「个人助手这种产品到底是什么」。它不替代 [W-028 对话型应用](../../../specs/work-pool/W-2026-028-study-conversational-agent-application-capabilities.md)：那边从用户任务看伙伴、客服、自动化；这里先看个人助手这一类产品，以及它和编程 Agent、框架的边界。

采用混合线，顺序是：类别边界 → 带日期的产品版图 → 以后只固定一个开源个人助手追一条消息链路 → 必要时用假数据做「不该行动」对照。本轮只完成前两步的初稿。

## 原始问题

> 开一个 personal agent 的学习专栏。顺便调研现在有哪些开源、闭源的 agent。
