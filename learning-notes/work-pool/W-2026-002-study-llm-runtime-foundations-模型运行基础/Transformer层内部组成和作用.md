# Transformer 层内部组成和作用

## 我的理解

> 经过很多 Transformer 层，每层包含 Attention，是吧？

对。输入会依次经过很多个 Transformer 层，每层都有 Attention，以及下面这些组成。

## 每层主要有什么？

| 组成 | 简单理解它的作用 |
| --- | --- |
| Attention（注意力） | 根据相关程度，从上下文中融合信息。 |
| FFN（前馈网络，也常叫 MLP） | 对每个 Token 位置的信息进一步加工。 |
| 残差连接 | 把加工结果加回这段计算的输入，在原有信息上更新。 |
| 归一化 | 调整数值尺度，让计算和训练更稳定。 |

先记住：**Attention 让不同 Token 之间交流信息；FFN 对每个位置的信息继续加工。**

## Attention 已经加工过了，为什么还要 FFN？

这部分我还不熟悉，需要继续理解。

> **Attention 重点是“从哪些位置取信息、各取多少”；FFN 则对取到的信息进一步做变换。**

FFN 加工的是**当前 Token 位置的向量，也就是表示信息的一串数字**。它通过训练学到的参数，对这些数字进行组合和变换。

例如「我 喜欢 吃 苹果」中，「苹果」这个位置经过 Attention 后，已经融合了上下文信息；FFN 接着加工这个位置的向量，本身不直接读取其他位置。

暂时省略归一化，只区分两个动作：

```text
B = FFN(y)   → FFN：加工 y，得到 B
z = y + B    → 残差连接：把 B 加回 y
```

**FFN 负责加工，残差负责加回去；FFN 不是残差机制。**

## 残差：用我的话理解

> 中间各个环节出来的结果，通过一种增量的形式，加到从上一层到这一层的输入里面。

“在原有信息上加一个增量”这个理解是对的。

只补充一点：**不是所有结果都加到同一个原始输入上，而是各自加回当前这段计算的输入。**

暂时省略归一化，只看残差怎么加：

```text
上一层传来的 x
    ↓
Attention 加工，得到 A
    ↓
y = x + A
    ↓
FFN 加工 y，得到 B
    ↓
这一层的输出 z = y + B
```

这里的“加”就是向量中对应位置的数字相加。增量可以为正、为负，也不一定很小。

## 和 Prefill 是什么关系？

**上面讲的是 Transformer 层内部各个环节的作用。**

Prefill（预填充）则是处理已知 Prompt 的整个阶段：输入经过模型的多个 Transformer 层，建立各层的 KV Cache，并得到用于选择第一个输出 Token 的预测。

所以，Attention 是 Prefill 中的一部分计算；后面的 Decode 也会使用 Attention。

这里只介绍常见结构。不同模型的细节可能不同；不是每经过一层就生成一个新 Token。

## 我的简单理解

Prefill是对输出层之前的所有Transformer的一个统称

都是用来预处理输入prompt的信息的

每个 Transformer 层里面都有各自的注意力机制。

## 教练校准

🟡 “Prefill 用来处理输入 Prompt”这个方向是对的，但它不是某一组 Transformer 层的名称，而是**一次推理请求中的运行阶段**。

在 Prefill 阶段，推理程序让已知 Prompt 经过输入适配、Embedding、全部 Transformer 层和输出头，建立各层的 KV Cache，并得到选择第一个输出 Token 所需的 Logits。后续 Decode 仍然会经过同一套模型层，只是每轮主要处理新加入的 Token，并复用已有 KV Cache。

更准确的表述是：

> Prefill 是模型处理已有 Prompt、建立推理状态并产生首 Token 预测的阶段；Transformer 层是模型内部反复堆叠的计算结构。

常见 Transformer 层通常不只有 Attention，还包含 FFN、残差连接和归一化；具体排列方式会因模型架构而不同。
