教练建议将中文意图识别与参数抽取作为首选候选，尚未视为用户已选择或替换原实验合同。

- [MASSIVE 官方项目](https://github.com/alexa/massive)、[数据卡](https://huggingface.co/datasets/AmazonScience/massive)：中文 zh-CN，数据卡列出 train 11,514、dev 2,033、test 2,974；60 类意图、55 类槽位。将现有标注转换为 JSON 目标，用于生成式 SFT。数据卡总览与切分表的总量口径不同，正式使用固定发布版本后按文件实数核对；不能混用不同版本数字。
- 业务例子：中文请求 → 意图与原文参数 → 程序校验 → 模拟工具。时间归一化、真实工具执行不属于原始数据集直接提供的能力。
- 首选实验建议：200 条只做链路验证；正式按 1,000 → 5,000 → 全部可用训练集做规模对照，固定 dev/test。短序列、0.6B 与 LoRA 优先在本机尝试，耗时与显存尚未实测。
- 原 W-027 的多 Schema 和 B1–B4 验收仍保留；固定格式的意图识别实验不能自动证明未见 Schema 泛化。
- [Bitext 客服数据](https://huggingface.co/datasets/bitext/Bitext-customer-support-llm-chatbot-training-dataset)：26,872 条英文问答、27 类意图；发布者标明为混合合成数据，适合客服分类或风格适配，不作为真实客户流水或企业政策依据。
- [Glaive function calling v2](https://huggingface.co/datasets/glaiveai/glaive-function-calling-v2)：112,960 行，存在工具描述、调用与普通聊天样本；页面 README 为空，质量和数据来源需进一步审计。适合后续窄范围工具调用实验，不作为初次训练首选。
