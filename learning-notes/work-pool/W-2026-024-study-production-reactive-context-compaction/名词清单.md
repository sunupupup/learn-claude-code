# 名词清单

> 先按知识块定位概念，再到知识图谱或模块笔记看数据流。掌握状态不由“读过定义”推定。

## 上下文与触发

| 术语 | 初学者解释与所属层次 | 容易混淆的概念 |
| --- | --- | --- |
| Context（上下文） | Harness/LLM 边界：一次模型请求可见的输入及其结构；不只是聊天记录。 | 持久化历史不等于当前请求上下文。 |
| Message History（消息历史） | Harness 消息协议中的按序消息集合，通常包括用户、助手和工具交互。 | 它是上下文的组成部分，不一定是全部上下文。 |
| Context Window（上下文窗口） | LLM Runtime 能处理的输入与输出 Token 容量限制。 | 本地估算值可能与服务端限制、计量口径不同。 |
| Proactive / Auto / Manual Compaction（主动/自动/手动压缩） | Harness 在调用前按规则、阈值或显式请求减少上下文。 | 触发时机不同于收到超限错误后的 Reactive Compact。 |
| Reactive Compact（应急上下文压缩） | Harness 在模型 API 拒绝输入过长后，压缩并尝试恢复的一条受限重试路径。 | 不是某一种固定摘要格式，也不是无限重试。 |

## 协议与状态

| 术语 | 初学者解释与所属层次 | 容易混淆的概念 |
| --- | --- | --- |
| Tool Call / Tool Result（工具调用/结果） | Harness 与模型之间表示工具请求及其返回值的消息内容。 | 两条消息可能由调用 ID 关联，不能只按条数裁切。 |
| Safe Cut Point（安全切点） | 压缩历史时选出的边界；裁切后消息序列仍满足协议和后续推理需要。 | “保留最近 N 条”不自动构成安全切点。 |
| Run State（运行状态） | 结构化保存的任务目标、约束、计划和完成进度等信息。 | 自然语言摘要不一定具备可校验字段。 |
| Checkpoint（检查点） | 为暂停/故障后的恢复保存的一致状态快照或恢复位置。 | Transcript 可能只是记录，不保证恢复所需状态齐全。 |
| Artifact（外置产物/引用） | 放在上下文外的原始结果、文件或证据，通过稳定引用按需取回。 | 磁盘上存在不等于模型自动能访问或有权限读取。 |

## 恢复与验证

| 术语 | 初学者解释与所属层次 | 容易混淆的概念 |
| --- | --- | --- |
| Idempotency Key（幂等键） | 业务/API 层用于识别重复写请求的键，避免重试重复产生副作用。 | 和 Tool Call ID 或消息 ID 的用途不同。 |
| Recovery Budget（恢复预算） | Harness 限制恢复次数、耗时、Token 或成本的上限。 | Retry 次数不一定等于模型调用总数或端到端预算。 |
| Trace（追踪记录） | 可观测性记录，用来关联触发、压缩策略、版本、重试和结果。 | Trace 不应默认保存全部敏感上下文。 |
| Eval（评测） | 用固定用例测量任务质量、协议有效性和恢复能力。 | 请求成功返回不代表任务语义保真或副作用安全。 |
