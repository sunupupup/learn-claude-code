# Agent 可观测、评测与持续优化：完整学习路径

> 顺序：官方案例走通闭环 → Pir 对照真实实现 → 生产实践补齐。每次一个小问题；当前只准备计划，各阶段均未验收。

1. **官方案例学习：[Langfuse Workshop](https://github.com/langfuse/langfuse-workshop)**（[详细路径](./refer/01-官方案例学习.md)｜[阶段自测](./refer/01-官方案例自测.md)）
   1. 先看基础 Agent：用户请求 → 模型 → 工具 → 最终回复（00–01）。
   2. 再接观测：Session / Trace / Span、输入输出、耗时、错误（02）。
   3. 关联提示词版本，再配置线上质量监控，找出可疑对话（03–04）。
   4. 建测试集：场景、输入、预期结果；运行 Agent，用规则与模型评委评分（05–06）。
   5. 改一个因素 → 重跑同一数据集 → 比较逐例结果 → 判断是否改善（07–08）。
   - **验收：**一条完整 Trace ＋ 一个可解释的修改前后实验；分清平台评测与本地评测。

2. **回到 Pir：从一条请求学真实工程链路**（[详细路径](./refer/02-Pir对照学习.md)｜[源码现状核验](./refer/Pir现状核验.md)｜[阶段自测](./refer/02-Pir项目自测.md)）
   1. 先固定源码版本，沿 BFF → Pir API → Runtime → 模型/工具 → SSE 走一轮请求。
   2. 再看三条数据流：观测事件、前端流事件、历史存储；核对 ID 关联与原文/摘要边界。
   3. 看 Langfuse 导出、BFF 内容采集与运行指标：记录产生、发送、平台可见分别如何确认。
   4. 从一个失败用例读 `pir-eval`：YAML → runner → 轨迹断言 → 报告 → baseline 对比。
   5. 再学问题导出与 replay：复现上下文、隔离副作用、区分结果未知与失败。
   6. 完成一个切片：问题 → 案例 → 定向修改 → 回归比较；列出线上评委、CI、告警和发布缺口。
   - **验收：**能解释 Pir 已实现什么、依赖哪些配置、哪些尚未运行/线上核验；不先通读全部项目。

3. **生产实践进阶：可靠测量、发布与持续迭代**（[专题与原始资料](./refer/03-生产实践进阶.md)｜[阶段自测](./refer/03-生产实践自测.md)）
   1. 先定义成功：答案质量 ＋ 轨迹合法 ＋ 真实业务结果。
   2. 补跨服务/异步关联、采样、脱敏、保留策略，以及观测系统自身可靠性。
   3. 建可靠 Eval：数据集版本、人工标注、评委校准、重复试验、分组分析、安全与副作用断言。
   4. 建监控与告警：业务成功率、延迟、错误、成本；SLI / SLO、错误预算、排查流程。
   5. 接发布闭环：固定基线 → CI 回归门禁 → 小流量灰度 → 观察/回滚 → 新案例回流。
   - **验收：**用一个 Pir 场景完成“发现 → 取证 → 复现 → 修改 → 验证 → 发布演练 → 回流”。

下一步只做 **1.1：官方案例结构与一次请求调用链**。源码、运行和线上证据分别标注；不自动推进后续实验或修改产品。
