# Browser Use 名词清单

按知识块查词使用，不代表已经掌握；具体实现随源码版本核验。

| 知识块 | 名词 | 初学者解释与边界 |
| --- | --- | --- |
| 整体链路 | Agent / Harness | Agent 是完成任务的整体；Harness 是围绕模型的执行程序，负责循环和工具调用，模型本身不直接点击网页。 |
| 页面观察 | DOM（Document Object Model，文档对象模型） | 浏览器中的网页节点结构，属于网页层；不同于整个桌面窗口结构，也不同于截图。 |
| 页面观察 | Accessibility Tree（可访问性树） | 用角色、名称等语义描述界面，服务于无障碍访问；和 DOM 有关联但不是同一棵树。 |
| 页面观察 | Screenshot（截图） | 渲染画面的像素图；能显示视觉布局，本身不携带 DOM 节点身份。 |
| 浏览器控制 | CDP（Chrome DevTools Protocol） | Chrome 开发者工具协议，属于浏览器控制层；不是模型协议，也不是所有浏览器自动化的唯一接口。 |
| 浏览器控制 | RPC / WebSocket | RPC 是远程过程调用思想，WebSocket 是双向通信通道；控制协议和传输通道是不同层次。具体消息格式待源码核验。 |
| 动作执行 | Locator（定位器） | 用属性、角色等规则找到元素；坐标则指定一个位置，两种定位方式不等同。 |
| 环境状态 | Session / Cookie（会话 / Cookie） | 会话表示连续交互的状态；Cookie 是浏览器保存并按规则发送的数据，可能关联登录身份。 |
| 结果验证 | Timeout / Unknown（超时 / 结果未知） | 等待超时说明没有及时收到预期结果；不直接证明点击或提交没有发生。 |
