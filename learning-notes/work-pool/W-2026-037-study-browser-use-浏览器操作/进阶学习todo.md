# Browser Use 进阶学习 Todo

后续选学地图，不是本轮必须完成的验收清单；勾选表示完成对应学习，不代表只看过关键词。具体产品能力、API 和源码版本在开始该项时重新核验。

建议优先：页面观察 → 稳定操作 → 结果验证 → 会话恢复；其他内容按场景选学。

## 1. CDP 与通信

- [ ] Domain / Method：常见协议领域、命令参数和错误响应。
- [ ] 请求与事件：请求 ID 匹配、事件订阅、异步消息分发。
- [ ] Target / Session：浏览器、标签页、iframe、Worker 的定位和会话路由。
- [ ] WebSocket 生命周期：连接、超时、断线、重连与未完成请求。
- [ ] 执行上下文：JavaScript 究竟在哪个页面、frame 和隔离环境中执行。
- [ ] 协议兼容：浏览器版本、实验性能力和客户端适配。

## 2. 页面观察与信息加工

- [ ] DOM / 无障碍树 / 截图：不同表示的适用场景与组合方式。
- [ ] 可访问名称：原生 HTML、label、ARIA 怎样形成控件名称和状态。
- [ ] 快照裁剪：按区域、深度、视口、交互候选减少噪声与 Token。
- [ ] 元素引用：ref、uid、DOM 节点标识怎样映射和失效。
- [ ] 增量观察：页面变化后更新哪些信息，避免每轮重复读取全页。
- [ ] 布局与遮挡：坐标、滚动、缩放、视口和元素可见性的区别。
- [ ] 文本与结构化提取：文章、表格、列表怎样保留有用上下文。
- [ ] 复杂界面：iframe、Shadow DOM、Canvas、虚拟列表的观察边界。

## 3. 稳定定位与操作

- [ ] Locator：角色、名称、文本、CSS、测试 ID 等定位方式的取舍。
- [ ] 可操作性检查：可见、稳定、启用、能接收事件，不只判断元素存在。
- [ ] 等待策略：等待元素、页面状态或响应，减少固定 sleep。
- [ ] 点击方式：DOM click、浏览器输入事件、屏幕坐标点击的区别。
- [ ] 表单交互：输入事件、校验、复选框、下拉框和受控组件。
- [ ] 页面生命周期：导航、重定向、新标签页、弹窗和对话框。
- [ ] 文件操作：上传、下载、路径映射和文件完整性检查。
- [ ] 特殊动作：拖拽、悬停、快捷键、剪贴板与权限提示。

## 4. 会话、账号与环境

- [ ] Profile / BrowserContext：数据目录隔离、上下文隔离和进程隔离。
- [ ] 认证状态：Cookie、localStorage、IndexedDB、过期和重新登录。
- [ ] 多账号路由：账号、任务、会话与页面之间的对应关系。
- [ ] 状态持久化：保留浏览器进程、保存认证数据与恢复任务的区别。
- [ ] 并发控制：目录锁、同一页面争用、任务互相干扰。
- [ ] 人工接管：登录、验证码、二次验证时暂停和恢复。

## 5. 工具与 Agent 设计

- [ ] 接口粒度：独立 MCP Tool、代码 API、CLI、整体任务工具的取舍。
- [ ] 工具描述：参数、返回值、失败原因和副作用如何表达清楚。
- [ ] 观察—行动闭环：每一步依据什么状态选择动作，再用什么确认结果。
- [ ] 批量动作：减少往返次数，同时保留必要的检查点。
- [ ] 浏览器扩展桥接：扩展 API、CDP、本地通信和工具服务的分工。
- [ ] WebMCP：网站注册业务工具，与界面操作、后端 API 的关系。
- [ ] 源码调用链：固定一个项目版本，追一遍 snapshot → click → result。

## 6. 验证、失败与恢复

- [ ] 完成证据：动作已发送、工具成功、页面变化和业务成功分开判断。
- [ ] 网络与控制台：结合请求、响应和脚本报错诊断失败。
- [ ] 幂等与重复操作：创建、提交、发布等动作重试前先核查结果。
- [ ] 结果未知：超时、断线或崩溃后如何确认操作有没有生效。
- [ ] 恢复检查点：保存目标、当前页面、产物和已确认进度。
- [ ] 重试预算：区分可重试错误、权限失败与需要人工处理的情况。
- [ ] 清理与补偿：失败后释放资源，必要时撤销已产生的业务变更。

## 7. 远程浏览器与服务管理

- [ ] 连接拓扑：外部直连 CDP，与沙箱内执行控制脚本的区别。
- [ ] 网络可达：localhost、端口映射、私网、隧道和认证网关。
- [ ] Browserless：浏览器启动、连接、保留、持久化与回收。
- [ ] E2B：模板、命令执行、文件、桌面与浏览器怎样组合。
- [ ] 文件流转：浏览器下载后怎样交给脚本处理并取回产物。
- [ ] 生命周期与容量：空闲超时、最大运行时间、并发限制和资源清理。

## 8. 安全、反爬与风控

- [ ] 权限分层：Harness 授权、工具限制、浏览器配置、系统隔离。
- [ ] CDP 暴露面：连接认证、能力限制和任意 JavaScript 的权限边界。
- [ ] 网页提示注入：页面内容不能自动升级为用户指令或授权。
- [ ] 网络访问边界：域名、重定向、子资源和内网访问限制。
- [ ] 敏感数据：账号凭据、截图、日志和认证状态文件的保护。
- [ ] 文件安全：下载内容、目录挂载、程序执行和宿主机访问。
- [ ] 反爬识别：验证码、限流和访问拒绝，按网站规则降低频率或转人工。
- [ ] 账号风控：异常登录、批量操作、二次验证和会话失效。
- [ ] 高影响动作：删除、付款、发布的授权、确认和审计。

## 9. 可观测性与评估

- [ ] Trace：串联工具参数、快照、截图、网络事件和执行结果。
- [ ] 最小复现：保存输入与环境，定位失败是模型决策还是工具执行问题。
- [ ] 对照实验：页面改版、加载延迟、遮罩、断线和登录过期。
- [ ] 任务指标：成功率、步骤数、耗时、成本和人工介入率。
- [ ] 性能优化：快照大小、截图频率、批处理和远程通信延迟。
- [ ] 回归验证：升级浏览器、工具或模型后，重跑典型任务。

## 可选最小实验

- [ ] 原始 CDP：读取标题 → 获取无障碍树 → 点击 → 检查结果。
- [ ] Playwright：用定位器和自动等待重做同一个任务，对照封装价值。
- [ ] 账号隔离：两个 Context 使用不同账号，验证状态不串用。
- [ ] 失败恢复：提交后模拟断线，查询结果后再决定是否重试。
- [ ] 远程迁移：将同一个任务移到远程浏览器，对照连接和文件流转。
