## 学习位置与方式

本模块承接基础 Agent loop（模型决策 → 工具执行 → 结果回到模型）与 s12 任务系统，连接完成验证、Memory、上下文压缩、后台执行和调度等专题。前置只要求理解一次工具调用与简单任务状态，不要求先学完全部关联专题。

采用混合线：先用常见场景建立概念，再读当前教学代码，按当前问题补固定版本的真实项目源码，最后做最小实验与失败恢复。**每次一个小问题，先让学习者判断，再讲解和校准。**

贯穿场景：整理 20 份本地资料，逐份生成带来源的摘要，形成汇总并按约定规则验收；先用 3 份资料讨论，不立即实现全部流程。

## 当前小问题与验收方式

场景：用户要求整理 3 份资料，每份摘要带原文引用，再生成总览。AI 回答“全部完成”，目录中也出现了 `summary.md`。

当前问题：**你会再检查哪些东西，才愿意确认这次任务完成？**

验收方式：学习者用自己的话提出最少必要检查，并说明各项检查能证明什么。当前不预写标准答案、不记录为已掌握。
