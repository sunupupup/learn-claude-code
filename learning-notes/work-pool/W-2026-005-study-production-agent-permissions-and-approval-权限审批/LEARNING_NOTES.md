## 常见场景主线

1. Agent 提议一个工具调用，Runtime 把主体、动作、资源、参数和上下文整理成明确请求；
2. 策略层给出 `allow / ask / deny`，并明确匹配的是谁、对什么资源、做什么动作；
3. `ask` 时先持久化待处理状态，向有权限的用户展示经过整理的请求，记录一次性、限范围、可过期的决定；
4. 恢复前再次验证调用内容、主体和授权是否仍有效，再交给实际执行器；
5. 执行器在沙箱/凭证边界内执行；审计关联请求、策略版本、审批者、结果和撤销事件。

本章必学还包括身份与短期凭证、多 Agent 最小权限委派、暂停/恢复/超时/撤销/重复消息、沙箱边界，以及审计和常见越权风险。低频策略语言能力、跨区域强一致权限图、微 VM 调优作为选学。
