## 课程主线与范围

**常用主线（必学）**

1. Host、MCP Client、MCP Server、模型和业务服务的责任边界；Tool Calling 如何由 Host 转成 MCP `tools/call`。
2. 固定协议版本；理解旧版 `initialize` 生命周期与 2026-07-28 无握手、按请求元数据协商/发现的差异。
3. JSON-RPC 消息、能力发现、Tools / Resources / Prompts、工具契约与错误。
4. stdio 与 Streamable HTTP：通信路径、进程/网络生命周期和信任边界。
5. 最小真实有用服务：选业务、读真实数据、选 SDK、接目标客户端；再按需求补认证、授权、可靠性、日志与运行手册。

**按场景选学**：订阅、多轮请求、任务/长运行操作、多租户 OAuth、高可用、多实例状态协调、复杂策略网关。任务卡要求所有生产维度都要评估；实现深度按真实用途判定，不能因为列入选学就漏掉适用验收。

学习模式为**混合线**：先用最小概念模型，再核对固定版本的官方规范/SDK 与代表项目源码，之后才设计可重复实验与生产证据。每轮只讲一个小问题；读过导航不等于掌握。
