有这么些方式

| 方式 | Agent 一开始看到什么 | 后续怎么用 |
|---|---|---|
| **启动时全部加载** | 已连接 MCP 的工具名称、描述、参数 | 直接调用工具 |
| **按需连接** | MCP 服务名称、简介，以及 `connect_mcp` 一类管理工具 | 先连接选中的服务，再获得它的工具 |
| **按需发现工具** | 工具搜索／发现入口 | 找到需要的工具后，才把具体定义提供给模型 |



| 项目 | MCP 连接与目录准备 | 模型侧工具使用 |
|---|---|---|
| **Pi** | 会话启动时，后台连接所有已启用的 MCP，获取并注册工具 | 默认通过 **Code Mode 搜索、查看、调用工具**；设为 `deferred` 才走独立的 `tool_search` |
| **Codex** | 启动阶段准备 MCP 目录；可以使用缓存，部分连接允许延后 | 模型支持且配置允许时，通过 **工具搜索按需暴露定义** |
