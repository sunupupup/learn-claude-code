# 开源项目 MCP 服务设计：项目比较与学习路线

> 资料核验日期：2026-09-26。链接均指向官方/维护者仓库或文档。维护、许可证、版本和功能会变化；开始源码学习时应固定 tag/commit，并复查对应文件与依赖许可证。产品自述是功能线索，不等于独立安全审计或“生产验证”。

## 为什么选这批项目

本列表覆盖不同技术层，不把同类 Server 堆在一起：官方规范定义线上合同；两个官方 SDK 展示语言实现；FastMCP 代表面向开发者的框架；Inspector 与 Conformance 分别提供交互式观察和自动协议契约检查；GitHub、Atlassian、Postgres 是不同数据域的业务适配；Docker MCP Gateway 与 agentgateway 展示本机隔离聚合和云原生身份/策略治理两种路径。共 **10 个有源码项目**，另列官方规范作为首要参考资料（规范不是应用项目，也不计入项目数量）。

## 三、部署认证与治理网关

| 方案 | 部署重点 | 值得对照的问题 | 不代表什么 |
|---|---|---|---|
| Docker MCP Gateway | 聚合本地/容器 Server，profile 控制接入工具，catalog 管理镜像/来源，集成 secret/OAuth 并记录调用元数据 | 本机 Server 启动、容器权限、profile 工具筛选、remote URL/Origin、镜像来源校验、secret 管理 | “工具被隐藏”不等于业务 API 授权；Docker Desktop 文档功能不保证在独立开源 CLI/其他宿主都相同 |
| agentgateway | 作为 MCP 流量入口，配身份认证、RBAC/CEL policy、限流、TLS、OpenTelemetry 和上游路由 | 入站 token 与下游凭据是否区分；多租户授权在哪执行；现代 protocol support 与产品文档的版本对齐 | GitHub 上有能力/示例不等于相应生产部署已验证；企业扩展需辨明哪些开放源码可用 |

两者互补而非升级替代：Docker 侧重开发机/容器化 Server 生命周期和客户端统一配置；agentgateway 侧重网络入口与云原生身份/策略管控。真实系统可组合，但组合会增加多个策略层和排障责任。

## 推荐阅读路线（初学者顺序）

1. **先画责任边界**：读 [规范与 Schema](./MCP官方规范与Schema.md) 的版本概览，再回到 [知识图谱](../MCP服务知识图谱.md) 回答“模型提出了什么、谁真正发出 MCP 请求”。
2. **从易读样例建立直觉**：读 FastMCP 快速开始；用 Inspector 观察一个已有 s19 Server。只观察、不默认安装。
3. **理解协议如何落到库里**：选 Python SDK 或 TypeScript SDK 为主读一个（首选 Python 作为初学对照 s19 既有代码），另一个只比较 Transport/版本支持，不并行深入两套源码。
4. **看真实业务边界**：GitHub MCP Server（先只读/最小权限）作为主项目，或若用户更常用 Jira/Confluence 则改选 MCP Atlassian。Postgres MCP 仅在具备安全测试库、只读账号和 SQL 前置知识时作为窄对照。
5. **最后看集中治理**：先 Docker Gateway 的 profile/容器/密钥流，再挑 agentgateway 的一项 OAuth 或 CEL 策略作对照。配置阅读不等同实测安全结论。

**首选建议**：概念/SDK主项目先 Python 官方 SDK（与 s19 Python 教学连续）；业务主项目 GitHub MCP Server（域模型真实、只读开关清晰、源码和发布活跃）；治理主项目 Docker MCP Gateway（可视化容器、凭据和策略职责）。如目标场景是远程多用户服务，再以 agentgateway 做最多一个窄对照。用户尚未选语言、业务、客户端，以上只是有证据的导航，不替用户做实现决策。

## 固定版本和证据规则

- 2026-09-26 核验了官方规范当前 `2026-07-28` 版本变更、官方 SDK 主线与项目的公开仓库/文档/license/release 状态；具体每个依赖树的逐文件许可审计未做。
- 目前只有文档核验，状态应写作 `documented`；没有克隆或源码链路，不能标 `source-verified`；没有执行任何项目，不能标 `observed-runtime`；更没有目标环境的 `production-proven`。
- 同名产品可能区分免费核心、托管服务、商业增强或单独 Registry 镜像。推荐笔记会标出证据边界；生产用途需核对当前目录实际 LICENSE、构建产物和 SaaS/商业功能边界。
