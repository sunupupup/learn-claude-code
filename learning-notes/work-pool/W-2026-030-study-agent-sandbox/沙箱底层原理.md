# windows

| Codex 的执行环境 | 使用哪套沙箱 |
|---|---|
| **Windows 原生环境**，例如执行 PowerShell | Windows 原生沙箱 |
| **WSL2 的 Linux 环境**，例如执行 Linux Bash | Linux 沙箱，使用 bubblewrap 等机制 |

WSL 全称是 Windows Subsystem for Linux，即“适用于 Linux 的 Windows 子系统”。先把它理解成：在 Windows 电脑里提供一个能运行 Linux 程序的环境。

我们先只看新版 MXC（Microsoft Execution Containers，微软执行容器）。
它使用 Windows 的 进程安全环境（Process Security Environment，PSEC）。你可以先理解成：给即将启动的进程附上一份由系统强制执行的资源访问规则。
