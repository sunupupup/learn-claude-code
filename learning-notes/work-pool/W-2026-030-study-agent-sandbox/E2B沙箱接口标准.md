# E2B 
E2B 首先是一个云沙箱产品和开源项目，它提供远程沙箱服务，以及操作沙箱的 SDK／API。

你会觉得它像“标准”，是因为其他平台也开始兼容它的调用接口，

在“AI Agent 的远程代码执行沙箱”这个细分领域，E2B 是一家有代表性、技术和生态影响力都值得研究的公司。

# 接口约定

| 约定范围 | 常见接口 | 具体约定什么 |
|---|---|---|
| **创建环境** | `Sandbox.create(template=..., envs=..., timeout=...)` | 用哪个模板、传哪些环境变量、运行多久 |
| **标识与生命周期** | `sandbox_id`、`Sandbox.connect(id)`、`kill()` | 一个实例有唯一标识；重连找到原实例；销毁结束这个环境 |
| **命令执行** | `sandbox.commands.run(command, cwd=...)` | 在指定目录启动命令，获取输出、错误输出和退出码 |
| **进程交互** | 后台执行、`commands.connect(pid)`、发送标准输入 | 长任务怎样启动、重新连接和继续交互 |
| **文件操作** | `sandbox.files.write/read/list/...` | 按沙箱内路径写入、读取和管理文件，传输文本或二进制内容 |
| **代码解释器** | `sandbox.run_code(code, language=...)` | 执行代码片段，返回日志、运行错误和结构化结果 |
| **执行上下文** | 创建、选择、删除 Code Context | 多次代码执行是否使用同一个解释器，变量和导入是否保留 |
| **服务访问** | `sandbox.get_host(port)` | 沙箱内启动服务后，怎样得到外部可访问的地址 |


可以提前创建不同模版的沙箱环境
构建模板后，会有模板 ID，也可以通过名称／标签引用它，再据此创建沙箱。
可以类比Docker镜像

Docker：构建镜像 → 镜像 ID／标签 → 创建容器
E2B：   构建模板 → 模板 ID／标签 → 创建沙箱
