## 学习位置与模式

承接 [s01 Agent Loop](../../../agents/s01_agent_loop/README.md) 与 [s02 Tool Use](../../../agents/s02_tool_use/README.md)，学习如何把观察和动作工具扩展到桌面。前置知识：工具输入/输出、模型与执行程序的区别；图像坐标、窗口焦点和系统接口在本专题补齐。

采用混合线：典型视觉闭环 → 结构辅助路线 → 固定版本演示源码 → 按需最小实验。先理解通常怎样工作，再讨论平台差异。

## 原始问题

> computer use，那这个呢？这种的底层一般是怎么实现的？大量截图 + 鼠标定位？

保留这一问题作为学习起点；此前聊天解释不等于已经掌握。
