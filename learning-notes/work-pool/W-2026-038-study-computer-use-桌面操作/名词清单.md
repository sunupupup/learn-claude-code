# Computer Use 名词清单

按知识块查词使用，不代表已经掌握；平台和产品实现需另行核验。

| 知识块 | 名词 | 初学者解释与边界 |
| --- | --- | --- |
| 整体链路 | Harness / Executor（执行器） | Harness 编排模型和工具；执行器把工具动作转成系统操作，二者不等于模型。 |
| 视觉观察 | Screenshot / Pixel（截图 / 像素） | 截图由像素组成，表示某个时刻的画面；通常不包含按钮的程序对象身份。 |
| 视觉观察 | OCR（Optical Character Recognition，光学字符识别） | 从图像识别文字；不等于理解整个界面或完成任务。 |
| 视觉定位 | Grounding（界面目标定位） | 将“搜索按钮”等语义目标对应到当前界面位置或对象；不负责整个任务的步骤规划。 |
| 系统输入 | Coordinate / Scaling（坐标 / 缩放） | 动作用位置需要与实际画面对应；模型看到的缩小截图坐标不一定能直接作为屏幕坐标。 |
| 系统输入 | Focus（焦点） | 当前接收键盘输入的窗口或控件状态；“窗口可见”不保证输入会发给它。 |
| 结构辅助 | Accessibility Tree（可访问性树） | 控件角色、名称和状态等结构化描述；与截图互补，覆盖程度依赖应用。 |
| 结构辅助 | UIA（UI Automation） | Windows 的界面可访问性与自动化框架，属于系统层；不是通用网页协议。 |
| 结果与恢复 | Observation / Verification（观察 / 验证） | 观察取得状态，验证将状态与成功标准比较；有截图不代表已经正确验收。 |
| 结果与恢复 | Unknown Outcome（结果未知） | 当前证据不足以确认动作是否生效；不应直接当作失败后无条件重复执行。 |
