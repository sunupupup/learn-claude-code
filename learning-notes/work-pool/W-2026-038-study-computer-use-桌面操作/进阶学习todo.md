# Computer Use 进阶学习 Todo

后续选学地图，不是本轮必须完成的验收清单；勾选表示完成对应学习，不代表只看过关键词。具体 API、产品能力和源码版本在开始该项时重新核验。

建议优先：窗口观察 → 目标定位 → 稳定输入 → 结果验证；Windows 内部机制按需深入，不作为前置门槛。

## 1. 工具与系统调用链

- [ ] 观察—行动循环：截图或读取控件，选择动作，再观察结果。
- [ ] 工具与 API：独立动作 Tool、MCP 的代码执行入口和内部方法如何分工。
- [ ] 原生执行器：追踪一次 click 从参数解析到系统调用及结果返回。
- [ ] 状态生命周期：窗口引用、截图 ID、控件索引何时失效。
- [ ] 能力探测：运行时识别平台、可用接口和权限，避免假设工具一定存在。

## 2. 窗口与画面捕获

- [ ] 窗口选择：区分应用、进程和窗口，避免同名窗口选错。
- [ ] 窗口状态：前台、后台、遮挡、最小化和关闭对操作的影响。
- [ ] Graphics Capture：从捕获会话、画面帧到模型图片的处理链。
- [ ] 截图范围：整屏、单窗口、弹出菜单和局部裁剪如何选择。
- [ ] 图像处理：缩放、编码、清晰度与模型输入成本的取舍。
- [ ] 截图时机：等待界面变化，避免读取加载中或已经过期的画面。

## 3. 视觉定位与坐标

- [ ] GUI Grounding：把目标描述对应到截图中的位置或区域。
- [ ] 定位来源：主模型预测、辅助定位模型、系统控件位置的差别。
- [ ] 坐标体系：截图、窗口客户区、屏幕坐标之间怎样换算。
- [ ] DPI 与多屏：缩放比例、负坐标和跨显示器移动的影响。
- [ ] 小目标定位：裁剪、放大与二次观察，减少密集界面的误点。
- [ ] 区域到点击点：从目标边界框选择有效位置，并处理遮挡和布局变化。

## 4. UIA 结构化操作

- [ ] Client / Provider：自动化程序与应用控件如何通过系统接口通信。
- [ ] 元素树视图：Raw、Control、Content 等视图如何取舍。
- [ ] 属性定位：名称、类型、AutomationId、层级与重复控件消歧。
- [ ] Control Pattern：Invoke、Value、Toggle、Selection、ExpandCollapse 的用途。
- [ ] 事件与缓存：监听状态变化，减少跨进程查询并处理过期元素。
- [ ] 覆盖边界：自绘控件、虚拟列表和缺失语义时怎样退回视觉路线。
- [ ] 混合定位：UIA 与截图互相核对，按任务选择执行方式。

## 5. 鼠标键盘与稳定输入

- [ ] SendInput：按下、移动、松开等事件如何组合成动作。
- [ ] 焦点管理：前台窗口、键盘焦点和文本插入点分别是什么。
- [ ] Unicode / 输入法：文字输入、按键模拟、输入法组合过程的差别。
- [ ] 组合键状态：修饰键顺序、异常中断和卡键恢复。
- [ ] 输入策略：模拟输入、UIA 设置值、剪贴板粘贴的语义与副作用。
- [ ] 滚动与拖拽：目标区域、距离、速度和操作后的验证。
- [ ] 人机并发：用户移动鼠标或切换窗口时如何检测冲突并暂停。

## 6. 验证、等待与恢复

- [ ] 完成证据：输入事件已发送，不等于应用接收或业务成功。
- [ ] 等待条件：用控件状态、窗口变化或画面结果代替盲目 sleep。
- [ ] 多源核对：结合截图、控件属性和最终文件判断是否完成。
- [ ] 弹窗与异常流程：处理权限提示、错误提示和意外窗口切换。
- [ ] 结果未知：动作后超时或断线，先查询再决定是否重试。
- [ ] 幂等与补偿：避免重复提交、发送、付款或删除，必要时撤销变更。
- [ ] 检查点恢复：保存目标、进度和证据，恢复后重新识别当前界面。

## 7. 远程桌面与运行环境

- [ ] 本机与远程：模型、执行器、桌面分别运行在哪里。
- [ ] 桌面会话：登录、锁屏、远程连接和分辨率变化对工具的影响。
- [ ] 桌面沙箱模板：预装应用、字体、输入法和自动化依赖。
- [ ] 文件流转：桌面产物、沙箱目录和外部下载接口如何衔接。
- [ ] 多任务隔离：账号、桌面会话和任务如何对应，避免共享输入冲突。
- [ ] 生命周期：环境创建、保留、恢复和资源回收怎样影响状态。
- [ ] 跨平台对照：Windows UIA、macOS Accessibility、Linux AT-SPI 的职责。

## 8. 权限与安全

- [ ] 权限边界：普通进程、管理员应用、UIPI 和 UAC 的操作限制。
- [ ] 窗口范围授权：只操作用户指定应用，防止目标窗口漂移。
- [ ] 屏幕提示注入：界面文字不能自动成为用户指令或执行授权。
- [ ] 敏感数据保护：截图、控件文本、剪贴板和日志的采集范围与脱敏。
- [ ] 高影响动作：发送、发布、付款、删除的授权与确认时机。
- [ ] 强制隔离：系统账号、文件权限、网络策略和虚拟机各限制什么。
- [ ] 人工接管：验证、异常和不确定状态下安全暂停、交接与继续。

## 9. 可观测性与评估

- [ ] 动作轨迹：串联截图、窗口身份、坐标、控件引用与执行结果。
- [ ] 失败归因：分清目标识别、坐标映射、焦点、权限和应用错误。
- [ ] 任务指标：成功率、误点率、耗时、成本和人工介入率。
- [ ] 对照实验：缩放、遮挡、布局变化、加载延迟和断线。
- [ ] 性能取舍：截图频率、UIA 查询范围和模型往返次数。
- [ ] 回归验证：工具、模型或应用升级后重跑典型任务。

## 可选最小实验

- [ ] 截图实验：对照整屏和单窗口捕获，观察遮挡及缩放的影响。
- [ ] UIA 实验：读取测试应用控件树，按引用设置输入框或触发按钮。
- [ ] 视觉实验：仅用截图定位同一控件，与 UIA 路线对照。
- [ ] 输入实验：在测试文本窗口输入、使用快捷键并读取结果。
- [ ] 失败实验：改变焦点或窗口位置，观察旧状态为什么失效。
- [ ] 远程实验：将同一个最小任务迁到桌面沙箱，检查环境和产物流转。
