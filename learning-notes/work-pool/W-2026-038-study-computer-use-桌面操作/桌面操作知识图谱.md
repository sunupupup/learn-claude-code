# 桌面操作知识图谱

**Computer Use 是桌面交互能力类别；截图和结构化控件信息是可组合的观察路线。**

## 完整技术链路

用户目标与成功标准 → 获取截图/控件状态 → 模型理解当前界面 → 选择点击、输入或等待 → Harness 校验并分发动作 → 系统执行器操作测试窗口 → 再观察 → 核对结果，继续、完成或报告未知。

这是通用学习框架，不是某个产品默认实现的断言。

## 概念之间的关系

- 视觉模型负责理解截图和提出动作；Harness 负责调用工具，执行器负责与系统交互。
- OCR（文字识别）只解决从图中读字的一部分问题；它不等于理解控件、规划步骤或验证业务成功。
- 可访问性树是结构化界面描述；UI Automation 是 Windows 提供的相关框架，不等于网页 DOM。
- 纯视觉、结构辅助可以组合；结构接口的覆盖程度依赖应用，不是对所有界面都有效。
- [Browser Use](../W-2026-037-study-browser-use-浏览器操作/浏览器操作知识图谱.md) 聚焦浏览器范围；两者可以在同一任务中配合。

## 主线与选学扩展

必学：截图闭环 → 视觉定位 → 系统输入与焦点 → 结构辅助 → 动作后验证与恢复。

选学：多屏、远程桌面、复杂拖拽、跨平台执行器；不提前扩展为完整桌面助手。
