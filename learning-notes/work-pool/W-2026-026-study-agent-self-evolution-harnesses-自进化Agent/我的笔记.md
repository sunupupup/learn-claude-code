| 概念 | 直观例子 |
|---|---|
| 自我改进 | Agent 从失败中总结规则，之后做任务更准确 |
| 递归自我改进（RSI） | Agent 改进了自己的诊断、修改或验证能力，因此下一轮能提出并筛选出更好的改进 |

现在比较火的概念
RSI：Recursive Self-Improvement，递归自我改进。
RSI 比一般的“自进化”多了一层：改进之后的系统，还能更有效地完成下一轮自我改进。

RSI 改进自己的同时，还能优化改进的策略
RSI 不仅改进系统完成任务的能力，还可能改进“怎样发现问题、提出修改和筛选修改”的策略，让后续自我改进更有效

# 普通的自进化

现在主要有 4 个方向
| 实现路线 | 改变的对象 | 代表研究 | 是否训练模型 |
|---|---|---|---|
| 经验积累 | 外部记忆、可复用技能 | Reflexion、Voyager | 不需要 |
| 策略优化 | 提示词、上下文策略手册 | GEPA、ACE | 不需要 |
| 程序自修改 | 工具、控制循环、执行框架 | DGM、Self-Harness | 可以固定模型 |
| 参数学习 | 模型权重或适配参数 | SEAL、Agent Lightning | 需要 |

4个方面
1. Memory优化
2. Prompt优化，一些预制 prompt 的优化，这部分主要是 “指导Agent干活” 的内容
3. Tool 等， 和上面不同，这边 “Agent干活的行为、程序”
4. 模型参数学习，后训练

核心的机制，伪代码：

执行任务 → 收集反馈 → 分析失败原因
                         ↓
                 提出候选修改
                         ↓
             在独立任务上评测、检查回归
                         ↓
                  接受或拒绝
                         ↓
                保存版本，必要时回滚

## prompt 优化

prompt的优化，这边得看prompt的读取方式是啥，如果是文件，那下一次loop就能直接更新了；如果是硬编码，就得重启

关于prompt优化的方式：
- 人工：人工发现一些bad case
- 自动：有个自动的优化器，不断的进行自动的分析结果、优化迭代、更新

| 工作 | 人工迭代 | 自动优化流程 |
|---|---|---|
| 发现失败 | 开发者看日志 | 程序收集记录并评测 |
| 分析原因、修改 Prompt | 开发者写 | 优化器调用 LLM 生成候选 |
| 比较效果 | 开发者组织测试 | 优化器自动运行对照评测 |
| 发布 | 人工决定 | 可以保留人工审核 |

## Tool的优化

举一个实际场景：编码 Agent 读取大型日志时，总把上下文塞满。
它原来的 read_log 工具，会把整个日志文件返回给模型。日志很大时，模型请求可能超限，任务失败。
普通的程序自修改流程可以是：
1. **收集失败证据。**系统记录哪个工具返回了多大内容、之后在哪一步超限。
2. **优化 Agent 分析原因。**它读取执行记录和工具源码，提出假设：“日志工具缺少分段读取能力。”
3. **优化 Agent 在候选副本中改代码。**例如给工具增加按行范围读取的能力，并在结果中返回下一段的位置。
4. **运行测试与任务评测。**检查小日志仍能正常读取、大日志可以逐段读取、末尾错误不会被漏掉，同时比较任务成功率和成本。
5. 通过后发布新版本；失败则保留旧版本。

这里改代码的是优化 Agent，执行与评测由程序组织。开发者预先规定可修改范围、测试标准和发布权限。这是教学场景，用来说明机制，不代表某个项目的默认实现。

## 自进化Agent现有方案

| 产品 | 实际提供的相关能力 | 对应我们讨论的哪类 |
|---|---|---|
| **Hermes Agent · Nous Research** | 从经验创建技能、使用过程中更新技能、跨会话保存记忆；官方文档还描述了回合结束后的后台改进检查 | **记忆 + 策略/Skill 改进** |
| **Letta** | 有状态的 Agent，维护长期记忆；技能可以保存在 Agent 自己的记忆系统中，持续携带和管理 | **记忆 + 可持续维护的技能** |
| **Lindy** | 面向业务自动化，Agent 可在工作流中创建、修改记忆，供后续任务使用 | **经验与规则积累** |
| **Relevance AI** | 面向业务 Agent；官方示例包括遇到未知问题向人求助、保存答案、下次复用 | **人工反馈驱动的知识积累** |


感觉其实大多数，都是 在 memory 和 skill 上面来优化

- 自动总结、更新 用户的记忆内容
- 自动抽出用户的流程化步骤，总结成一个可以服用的skill和脚本
