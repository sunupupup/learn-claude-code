## 本章目标

通过 CrewAI 与 AutoGen 两个框架理解常见多 Agent 协作是怎样被组织和执行的。重点掌握控制流、任务/消息传递、状态、工具和结果验收，并学会判断何时多 Agent 的协调开销值得付出。

## 证据与记录原则

- `documented`：官方文档说明，不自动等同源码或运行时行为。
- `source-verified`：固定版本源码中追到的实现；记录仓库、Commit、路径和行号。
- `observed-runtime`：由可重复运行得到的观察；记录环境、输入和输出。
- `production-proven`：真实生产证据；框架 Demo 或本地运行不构成此类证据。
