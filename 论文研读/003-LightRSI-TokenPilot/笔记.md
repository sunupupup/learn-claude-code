# TokenPilot: Cache-Efficient Context Management for LLM Agents（LightRSI 项目）

LightRSI 是承载可复用改进能力与宿主集成的模块化运行项目；TokenPilot 是其关联论文及首个预设组件组合。2026-10-13 已核对论文摘要与官方仓库，尚未进行源码研读或运行验证。

## 核心论点

长会话 Agent 的上下文会不断增长，而直接删减或重排内容可能改变提示词前缀，破坏提示词缓存（Prompt Cache，对重复输入前缀的计算复用），因此更少的 Token 不一定带来更低的实际成本。TokenPilot 提出兼顾缓存的上下文管理：全局通过输入感知压缩稳定提示词前缀、在信息进入时减少环境噪声；局部通过生命周期感知淘汰，保守地批量卸载已失去任务相关性的上下文片段。论文主要研究上下文与成本管理；它被集成到 LightRSI，并不单凭项目名称证明系统会递归改进自身的改进能力。
