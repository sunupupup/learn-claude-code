# 学习新对话 Prompt 设计

## 目标

让学习者在新开对话时，通过附带一个文件恢复稳定的学习节奏和章节上下文要求。

## 决策

在根目录新增 `PROMPT_BEFORE_NEW_CHAT.md`，作为可直接 `@` 的新对话启动 Prompt。每次新对话由学习者补充当前章节目录，例如 `当前章节：s02_tool_use`。

## 内容边界

- 文件只包含跨章节稳定的教学规则、笔记规则、代码注释规则与验收目标；
- 章节知识、个人疑问与掌握状态保留在各章节的 `LEARNING_NOTES.md`；
- 不修改原教程 README；
- 不自动包含未明确指定的章节内容。

## 验证

检查 Markdown 文件存在、内容包含启动读取清单、渐进式教学规则、笔记规则与章节结束验收标准。
