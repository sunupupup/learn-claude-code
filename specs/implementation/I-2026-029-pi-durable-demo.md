# Pi Durable 视频确认 Demo 实现与核验

- 日期：2026-10-27
- Change：[C-2026-032](../changes/C-2026-032-pi-durable-demo.md)
- 范围、设计和使用唯一入口：[README](../../practice/pi-durable-demo/README.md)。

实现通用流式对话助手网页、Node HTTP/SSE 后端、Pi Durable 视频工具与两阶段子任务。
提供 Windows 一键启动，服务就绪后自动打开页面；直接打开 HTML 时提示正确入口。
`app.videos` 保存参数、用户决定和结果，Task 保存执行阶段；重启工具调用复用同一子任务。
审批接口校验参数，重复确认同一份参数幂等，已批准后不能覆盖成另一份参数。
服务使用仓库根 `.env` 的 DeepSeek 配置；未复制、显示或修改密钥。
视频是 Mock，不产出真实媒体文件，网页和模型说明均区分模拟与真实结果。

版本：`pi-durable`、`pi-ai`、`chord` 1.0.0；接口核对本地源码
`a13d35a742c6ef8462812a28fbe1d8c8b7431c32` 及 npm 固定版本类型定义。

## 已验证

在仓库外临时目录复用固定依赖，安装过程禁用生命周期脚本：

- `npm run check`：TypeScript 5.9.3 严格类型检查通过。
- Node 对后端、业务模块和前端 JS 的语法检查通过。
- 固定版本 DeepSeek Provider 可从本地模型目录解析 `deepseek-flash`，未调用供应商 API。
- `npm test`：5 个测试通过，3 个消息展示测试和 2 个离线任务测试；任务测试使用 Pi 自带 faux 模型，无网络调用。
  - 未确认不生成；重新读取状态保持 pending。
  - 关闭 Harness、重开同一 SQLite 后仍待确认。
  - 批准修改后的参数；重复批准幂等，不同参数覆盖被拒绝。
  - 生成阶段再次重开 SQLite，checkpoint 保持不变，同一任务最终完成。
  - 同一 requestId 不重复创建用户输入，历史包含成功 toolResult。
  - 拒绝后不生成；非法参数不能得到批准。

离线测试数据库建于系统临时目录，并在检查目录范围后清理；浏览器验收数据库另见下节。

## 边界

上述验证不包括断电、硬盘故障和所有自然语言请求的工具选择准确率。
真实视频供应商的任务查询、幂等、计费与结果未知窗口不在本次 Mock 范围。
当前是本机单用户共享会话，无账号和多租户隔离。模型调用使用已有配置，未复制或显示密钥。
