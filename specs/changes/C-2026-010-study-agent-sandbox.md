## Objective 与范围

理解工具实际执行时，文件、进程、网络、凭证、资源和生命周期如何被约束。以常用场景为主，不追求穷尽隔离技术。新主题直接启动，无已有同名 Work Pool 卡需要移除。

关联 [W-2026-005 权限审批](C-2026-015-study-production-agent-permissions-and-approval.md)及 [W-2026-006 副作用工具安全](C-2026-016-study-side-effect-tool-security.md)（链接已于 2026-09-26 随其流转更新）：本章聚焦执行隔离，完整身份治理、审批协议和业务事务由关联任务承接，本次不推进这些关联任务。

## 模式与预期产物

D1 概念起步，逐步进入 D2 场景判断；采用混合线，先理论与本地教学源码对照，再按实际问题选择一个隔离实现进行最小实验。产物为知识图谱、总笔记及逐节确认的中文模块笔记；实验目录按需创建。

## 必学验收

- 能解释沙箱位于工具执行层，并区别于提示词、审批、工作目录和上下文隔离。
- 能判断编码、数据分析、依赖安装、浏览器、远程 API、多任务场景需要限制哪些资源。
- 能解释进程、容器、虚拟机的基本边界，以及隔离强度、兼容性和开销的取舍。
- 能描述创建、执行、超时/取消、产物回收、清理与复用流程，指出外部副作用不能靠销毁沙箱撤销。
- 用复述和典型案例判断验证理解；进入实验后须保留一个正常案例与一个拒绝/失败对照的真实证据。
