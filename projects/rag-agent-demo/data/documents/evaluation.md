# Agent 评测

## Eval Set

Eval Set 是一组可以重复运行的代表性输入、期望结果和评分规则。它至少应包含正常问题、无答案问题、权限边界、错误恢复和恶意内容，而不能只包含成功 Demo。

## 评测维度

最终答案评测回答是否正确且有来源；轨迹评测检查是否按要求调用工具、参数是否正确和是否超过预算；组件评测分别检查检索召回、引用和权限过滤。延迟、Token、成本和错误率也应记录。

## 证据与评分

确定性断言优先用于 JSON Schema、来源 ID、租户过滤和工具次数。主观质量可以人工评分或使用校准过的模型评分，但 LLM judge 不能被当作唯一真值。
