# Tool 与权限

## Tool 契约

Tool 是由应用程序执行的普通函数或 API。模型只能提出结构化的工具请求，应用必须校验参数、身份、权限和预算后才执行。只读查询可以重试；有副作用的写操作还需要幂等键、审计和人工确认。

## 认证与授权

认证回答“你是谁”，授权回答“你能访问什么”。文档权限应作为 metadata 保存，例如 tenant_id、allowed_groups 和文档状态。检索时必须根据当前用户构造 datastore filter，授权过滤应发生在向量排序前。

## 不可信内容

文档和 Tool 返回值是数据，不是系统指令。恶意文档可能包含 Prompt Injection，诱导模型泄露秘密或调用不应调用的工具。系统指令、Tool Schema、程序权限和数据库过滤不能被文档正文覆盖。
