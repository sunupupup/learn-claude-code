# Agent 基础

## Agent 与 Workflow

Agent 是由模型驱动部分工作流决策、在限定边界内使用工具推进目标的应用系统。Workflow 则通常由程序预先固定步骤和分支。两者可以组合：程序固定权限和停止规则，模型只在允许的动作中选择下一步。

## Agent Loop

一次受控循环通常包含观察当前上下文、选择动作、执行工具、读取工具结果和判断是否完成。循环必须有最大轮次、超时、错误处理和成本预算。模型请求调用工具不代表工具已经获得授权或已经执行。

## State

State 是程序为正确执行保存的结构化事实，例如 run_id、当前阶段、工具调用次数、已检索 chunk_id 和最终状态。State 不等于长期 Memory；本项目只保存一次 Run 的状态。
