# 真实生产问题

从一个简单的 Agent Loop（智能体循环）出发，每次遇到一个具体生产问题，就新增一章，讲清问题场景、处理位置和源码依据。

使用根目录的 [Prompt 5](../PROMPT_5_PRODUCTION_LOOP_PROBLEMS.md) 开始学习。学习规则与章节模板统一维护在那里。

每个问题放在独立的 `NNN-具体问题中文名/` 目录，目录内统一使用 `笔记.md`。同一问题继续补充原笔记；目录命名、正文结构和维护规则见 [Prompt 5](../PROMPT_5_PRODUCTION_LOOP_PROBLEMS.md#问题目录)。

例如“工具参数格式错误后如何修正”“工具执行超时后如何避免重复操作”都可以独立成章；这些只是选题示例，尚未启动。
