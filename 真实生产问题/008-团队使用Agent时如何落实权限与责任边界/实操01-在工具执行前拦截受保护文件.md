# 实操 01：在工具执行前拦截受保护文件

> **具体防护场景：** 防止 Agent 在修改页面时，顺手改掉 .env 中的连接配置，或修改 .git、.claude、.cursor 中的内部文件和治理配置。通过文件编辑工具执行前的 Hook 检查目标路径，命中保护范围就拒绝本次修改。

## 场景

团队使用 Claude Code，允许 Agent 修改项目代码，但禁止文件编辑工具修改 `.env`、`.git/` 及治理配置。

## 配置代码

需要 Python 3；以下命令写法用于 Linux / macOS / WSL。把文件放到**需要治理的业务项目**，本文件只提供完整配置和代码。

**文件一：`.claude/settings.json`**。已有配置时合并 `hooks`，不要覆盖其他项。

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "python3 \"$CLAUDE_PROJECT_DIR/.claude/hooks/protect_files.py\""
          }
        ]
      }
    ]
  }
}
```

**文件二：`.claude/hooks/protect_files.py`**。

```python
import json
import os
import sys
from pathlib import Path


def deny(reason):
    # PreToolUse 退出码 2：本次工具调用不执行，原因返回给 Agent。
    print(reason, file=sys.stderr)
    raise SystemExit(2)


def main():
    try:
        event = json.load(sys.stdin)
        root = Path(os.environ["CLAUDE_PROJECT_DIR"]).resolve(strict=True)
        raw = event["tool_input"]["file_path"]
        if not isinstance(raw, str) or not raw.strip():
            deny("缺少目标文件，拒绝修改。")

        target = Path(raw)
        if not target.is_absolute():
            target = root / target
        # 先解析已有的符号链接，再按真实位置判断；不靠字符串前缀。
        target = target.resolve()
        try:
            relative = target.relative_to(root)
        except ValueError:
            deny("目标在项目目录之外，拒绝修改。")

        parts = [part.casefold() for part in relative.parts]
        filename = target.name.casefold()
        if filename == ".env" or filename.startswith(".env."):
            deny("环境变量文件受保护，拒绝修改。")
        if any(part in {".git", ".claude", ".cursor"} for part in parts):
            deny("Git 内部文件或治理配置受保护，拒绝修改。")
        # 返回 0，让原本的工具权限流程继续，并非授予额外权限。
        return 0
    except Exception:
        # 解析、路径或文件系统异常同样拒绝，不把异常当作允许。
        deny("无法确认目标路径，拒绝本次修改。")


if __name__ == "__main__":
    sys.exit(main())
```

管理员强制下发时，将同样的 Hook 注册放入组织托管设置，并部署受保护的脚本绝对路径；项目文件本身可由成员修改，不能据此声称团队策略不可撤销。

## 能起到的作用

- `Edit` / `Write` 修改受保护文件时，在执行前拒绝，并返回具体原因。
- 这里只拦截这两个文件工具；终端、MCP、人工编辑不在本示例覆盖范围内。
- 按官方协议编写，未运行。依据：[Hooks 示例](https://code.claude.com/docs/en/hooks-guide#block-edits-to-protected-files)、[托管配置](https://code.claude.com/docs/en/managed-settings)。
