# 实操 06：为工具调用保留身份和结果审计

> **具体防护场景：** 防止工具操作出问题后，只剩一句“Agent 说执行成功”，却无法查清哪个用户、哪个会话调用了什么。通过 MCP 网关记录验签后的身份、工具和会话信息，并按需保留参数、返回值和错误；这是追踪与告警依据，不是执行拦截。

## 场景

团队通过 MCP 网关调用工具，需要记录“哪个身份、哪个会话、调用什么、返回什么”，而不只看 Agent 最后的自然语言回答。

## 配置代码

使用 agentgateway。前提和账号认证方式同[实操 02](./实操02-MCP网关按用户身份分配工具权限.md)。

**文件：`agentgateway-audit.yaml`**。将示例身份服务地址改成实际值。

```yaml
frontendPolicies:
  accessLog:
    # 只记录工具调用，避免把整套发现列表反复写入日志。
    filter: 'mcp.methodName == "tools/call"'
    add:
      actor_id: 'jwt.sub'
      tool_name: 'mcp.tool.name'
      target_name: 'mcp.tool.target'
      # 示例仅给 echo 工具记录输入输出，其他工具默认不保存内容。
      # 接真实业务工具时，应先实现字段级脱敏，而非直接复制全量参数。
      tool_args: 'mcp.tool.name == "echo" ? mcp.tool.arguments : null'
      tool_result: 'mcp.tool.name == "echo" ? mcp.tool.result : null'
      tool_error: 'mcp.tool.name == "echo" ? mcp.tool.error : null'

mcp:
  port: 3333
  policies:
    mcpAuthentication:
      issuer: https://id.example.com/
      audiences:
        - https://mcp.example.com/mcp
      jwks:
        url: https://id.example.com/.well-known/jwks.json
      jwtValidationOptions:
        requiredClaims: [exp, aud, sub]
      resourceMetadata:
        resource: https://mcp.example.com/mcp
        scopesSupported: [tools:use]
        bearerMethodsSupported: [header]
    mcpAuthorization:
      rules:
        - allow: 'jwt.sub == "user-a" && mcp.tool.name == "echo"'
        - allow: 'jwt.sub == "user-b" && mcp.tool.name == "get-sum"'
  targets:
    - name: everything
      mcp:
        host: https://servereverything.dev/mcp
```

启动并保存日志（Linux / macOS / WSL）：

```bash
# 限制新建日志文件权限，日志不要放到可公开访问的 Web 目录。
umask 077
mkdir -p ./private-logs
agentgateway -f agentgateway-audit.yaml >> ./private-logs/mcp-access.log 2>&1
```

Cursor 的 MCP 连接配置与[实操 02](./实操02-MCP网关按用户身份分配工具权限.md)一致。两个配置文件选择一个运行，不要让它们同时占用 3333 端口。

## 能起到的作用

- 工具请求与验签后的 `jwt.sub` 关联；网关默认结构化日志还包含 MCP 会话、目标和工具等信息。
- `echo` 的输入、结果、错误被显式加入访问日志；其余工具只留关联信息，不保存业务内容。
- 日志保留在程序层面，不要求模型自行补记；它不阻止操作，也不能证明超时的外部操作一定失败。
- 按官方配置接口编写，未运行；真实日志留存、脱敏和防篡改需按部署环境设置。依据：[MCP 日志配置](https://agentgateway.dev/docs/standalone/latest/documentation/mcp/mcp-observability/)、[JWT 与 CEL 变量](https://agentgateway.dev/docs/standalone/latest/documentation/configuration/security/mcp-authz/)。
