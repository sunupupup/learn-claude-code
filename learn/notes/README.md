# 学习笔记

每章一个文件，命名与教程目录一致：`sXX_<主题>.md`。

## 笔记是什么

对话里问过的 **每一个问题**，消化后都要落到对应章节的 md 里——这是学习积累的主阵地，不是可选的。

总索引与协作约定见根目录 [`AGENTS.md`](../../AGENTS.md)。

## 建议结构

1. **格言** + 教程/代码路径
2. **核心概念** — 问答中搞懂的概念
3. **代码要点** — 关键函数、数据流
4. **实验记录** — prompt、trace、观察
5. **疑问与心得** — 踩坑、对比、扩展阅读

新问题讲透后，由 AI 主动归类写入上述区块，可适当扩展。
